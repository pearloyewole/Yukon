# Yukon — three.js visualizations

This is a minimal Vite + three.js scaffold to start building interactive 3D visualizations.

Quick start

```bash
cd /Users/pearloyewole/yukon
npm install
npm run dev
```

Open http://localhost:5173 in your browser (Vite prints the exact URL).

What you get

- `index.html` — simple entry that loads `/src/main.js` as a module
- `src/main.js` — a small example scene with a rotating cube and OrbitControls
- `src/style.css` — minimal styles
